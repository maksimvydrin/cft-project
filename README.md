# 🚀 cft-project: Симулятор Service Desk

Учебный проект Service Desk с системой умного распределения задач (Smart Routing), поддержкой ролевой модели (RBAC) и симуляцией рабочих смен. Проект демонстрирует алгоритмический подход к балансировке нагрузки (Workload Balancing) в службе технической поддержки.

## 🌟 Ключевые возможности

* **Умная маршрутизация (Smart Routing):** Алгоритм автоматически распределяет задачи с учетом их приоритета, текущей загрузки сотрудников и их уровня компетенции (задачи High уходят строго на L3, Low — распределяются равномерно).
* **Ролевая модель доступа (RBAC):** Разделение интерфейса и прав для Суперадмина (полное управление очередью и логами) и Аналитика (управление личным статусом на смене, закрытие/эскалация своих тикетов).
* **Сценарии нагрузок (JSON Loader):** Возможность на лету переключать "слепки" системы (`morning_shift.json`, `night_shift.json`, `stress_test.json`) для проверки алгоритма при разных потоках заявок.
* **Системное логирование (Audit Trail):** Встроенный терминал для чтения логов (`system.log`), фиксирующий маршрутизацию задач и действия пользователей.

## 🛠 Технологический стек

* **Backend:** Python 3.15, Flask
* **База данных:** SQLite (встроенная, перезаписывается через JSON-сценарии)
* **Frontend:** HTML5, CSS3, Vanilla JS (с Excel-подобными фильтрами без перезагрузки)
